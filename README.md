# toolswitch

14 everyday tools in one tiny app that waits in your tray: clipboard history, text from
screen, wallpapers, reminders, breaks, file compressor, background remover, PDF signing,
tidy downloads, backup, clean up, PC monitor, shut down timer and updates.
Windows, macOS and Linux. Offline, no account.

**Website:** https://berchj.github.io/toolswitch/

## Download

Get the file for your system from the [latest release](../../releases/latest):

| System | File |
|---|---|
| Ubuntu, Debian, Mint | `toolswitch_X_amd64.deb` (double-click it, or `sudo apt install ./toolswitch_X_amd64.deb`) |
| Other Linux | `toolswitch-vX-linux-x86_64.tar.gz` (unpack it and run `toolswitch`) |
| Windows 10/11 | `toolswitch-X-windows-x86_64-setup.exe` |
| Mac with Apple chip | `toolswitch-vX-macos-arm64.dmg` |
| Mac with Intel chip | `toolswitch-vX-macos-x86_64.dmg` |

The installers aren't signed with a paid certificate yet. On Windows click **More info → Run
anyway**; on macOS open **System Settings → Privacy & Security → Open Anyway**.

This repository only holds the downloads.
